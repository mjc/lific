- Lific prepends the mounted-endpoint, navigation-owner, and scoped-mount helpers, then applies forty-four reversible transformations. They cover mounted HTTP paths and logical page Run paths, no-HTTP-fallback connected refresh, raw compact signal JSON with legacy-only comment decoding, JSON expression and shard marker parsing, scoped `@mount` and ordinary event contexts, native Event access, vector signal writes and helpers, Unicode uppercase/scalar operations, ECMAScript trimming, procedure keepalive/manual redirects, document-wide redirect arbitration including runless socket redirects, scoped render-error events, fresh page socket ownership, programmatic native navigation, and cancellable page-owner commit/transfer events.
- The fork bundle already contains compact signal marker parsing, deferred local closures, tuple surrogates, and the shared document WebSocket Run/Stop protocol; the Lific patches retain those implementations.
- `transport.test.cjs` reconstructs the original baseline by removing the exact helper prefix and reversing each declared transformation, then checks its SHA-256. Node VM tests cover the packaged JSON marker parser without a browser.
